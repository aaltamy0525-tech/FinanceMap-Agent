# FinanceMap-Agent
By Ah-Yeong Kim

FinanceMap-Agent · 회계 AX 에이전트 허브
공시된 손익계산서를 붙여넣으면 AI 에이전트가 양식 인식 → 계정 매핑 → 분개·시산표 → 공시 소계 대조 검증 → 엑셀 리포트까지 처리하는 웹앱입니다. 금액 계산은 규칙 엔진(코드)이 하고, 규칙이 모르는 판단(처음 보는 항목의 매핑, 검증 실패 원인 진단, 말로 하는 계정코드 변경)만 Claude가 맡습니다. AI 제안은 반영 전에 검증 시뮬레이션과 관리자 승인을 거칩니다.

바로 실행
온라인 시연: https://aaltamy0525-tech.github.io/FinanceMap-Agent/
오프라인: index.html을 내려받아 크롬·엣지에서 열면 됩니다. 설치는 필요 없습니다.
Claude 연결(선택): 왼쪽 아래 [Claude 연결 설정]에 본인의 Anthropic API 키를 넣으면 Claude가 직접 판단합니다. 키가 없어도 내장 규칙 기반 모드로 전 과정이 동작합니다. 키는 그 브라우저에만 저장되며, 이 저장소에는 키가 들어 있지 않습니다.
시연 순서 (약 10분, LG디스플레이 2025 사업보고서 기준)
[① LG디스플레이 2025 공시 실행]: 7단계 파이프라인을 실행합니다. 결과는 검증 24/24 PASS이며, 원래 엑셀(파워쿼리) 결과와 같은 숫자가 나옵니다.
[관리자 모드] 켜기 → [② 항목명이 바뀐 공시]: 처음 보는 항목 '관계기업투자손익'이 나오면 AI가 '지분법손익'으로 매핑을 제안합니다. 제안에는 적용 시 24/24 PASS라는 시뮬레이션 결과가 함께 표시되고, 승인하면 자동으로 다시 실행됩니다.
[③ 2025년부터 연구개발비 코드 변경]: 회계연도별 규칙표에 변경안을 올리고 승인합니다. 2025년부터만 새 코드가 적용됩니다.
[엑셀로 내보내기]: Raw, Mapping, 쿼리1, Trial_Balance, Validation, 변경이력 시트가 담긴 xlsx 파일을 받습니다.
화면 구성은 오른쪽 위 [화면 설명] 버튼을 누르면 17개 부분을 차례로 짚어 설명합니다.

주요 기능
기능	설명
양식 자동 인식	기수·당기·전기·연도·FY 머리글, 주석 열, 3개월·누적 열, YoY·분기 열, 비용 부호 표기(음수·괄호·양수), 2줄 머리글
붙여넣기	DART·엑셀에서 복사한 표를 그대로 붙여넣으면 바로 실행 (엑셀·CSV 파일도 가능)
계정 매핑	키워드 규칙표로 매핑합니다(긴 키워드 우선). 규칙에 없는 항목은 AI가 근거와 검증 시뮬레이션을 붙여 제안합니다
시산표·검증	차변·대변 분개와 연도별 시산표를 만들고, 공시 소계(직전 소계 + 사이 항목), 순이익, 대차, 계정 방향을 대조합니다
자가수정	검증이 실패하면 원인을 진단합니다. 규칙표로 고칠 수 있으면 수정안을 내고, 원문 자체가 안 맞으면 근거와 함께 보고합니다
규칙 관리	매핑 규칙표를 회계연도별 버전으로 관리하고, 변경은 관리자 승인을 거칩니다. 모든 변경은 변경이력에 남습니다
시험 결과
DART·회사 IR에 공개된 실제 공시로 시험했습니다.

원문	양식 특징	검증
LG디스플레이 2025 사업보고서	3개 연도, 비용 음수 표기	24/24 PASS
삼성전자 2022 연간	비용 양수, 주석 열, 띄어 쓴 항목명	17/17 PASS
삼성전자 2025 반기	3개월·누적 열	17/17 PASS
네이버 2022 반기	원 단위, 영업수익·영업비용, 중단영업	17/17 PASS
붙여넣기 변형 6종	당기·전기 머리글, 괄호 텍스트, 비용 양수, 연도 오름차순, FY 머리글, 2줄 머리글	각 17/17 PASS
카카오 2024 IR 요약표	연도 오름차순, YoY·분기 열	9/15 (요약표의 반올림과 빠진 행 때문에 공시 숫자끼리 맞지 않음. 에이전트가 원인을 설명)
한계
일반 기업의 K-IFRS 손익계산서만 다룹니다. 재무상태표, 현금흐름표, 금융회사(은행·보험·증권) 손익계산서는 아직 지원하지 않습니다.
표를 복사할 수 있는 형태여야 합니다. 스캔 PDF나 이미지는 읽지 못합니다.
계정코드는 시연용으로 정한 임의 체계이며, 실제 회사의 계정과목표가 아닙니다.
만든 과정
v0: 엑셀 + 파워쿼리. AI로 M 코드 초안을 만들고, 결과를 공시 소계와 직접 대조하며 고쳤습니다.
v1: 웹으로 이식. 회계연도별 관리자 모드와 AI 매핑 제안을 추가했습니다.
v2: 다른 회사 양식을 지원하도록 양식 인식 엔진을 다시 작성했습니다.
v3: 에이전트 허브로 재구성했습니다. 실행 파이프라인, 검증 실패 자가수정, 말로 하는 규칙 변경, 화면 설명을 넣었습니다.
데이터와 라이선스
재무 데이터는 모두 DART와 각 회사 IR의 공개 공시입니다. 다른 회사의 내부 자료는 포함하지 않았습니다.
사용 라이브러리: SheetJS(xlsx 0.18.5, Apache-2.0), Anthropic TypeScript SDK(MIT). 두 라이브러리 모두 index.html 안에 들어 있습니다.
